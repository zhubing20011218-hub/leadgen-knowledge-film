- `brief.json`：访谈结果。**证据里的数字是示例**（`"example": true`），片上每个数字都标「示例」，这条片不能发布。
- `film.json`：`python3 scripts/ds_make.py` 全自动做出来的（deepseek-flash，不开思考，2026-11-17）：
  按「画面先行」写 → 检查（第一轮 1 个错，改一轮通过）→ 看图评审 → 按评审改 → 复查通过。共花 ¥0.047（空闲时段），没用到 pro。
  15 句、4 章、4 个画面（一个画面撑 3–4 句）：人生节点在第 2 句裂开 → 三条路一句划掉一条、盖「没回音」→ 一对雨刮的账一句一个数 → 出路一句一步、盖「去主页」。
  屏上的数全部来自 brief（十年、两百份、10 / 30 / 8 元、两万），没有编出来的数。
- 不完美的地方（留着给你看模型会怎么写偏）：「投简历」是死路却被当成 pick 点亮了；那组账的四个数意思不同（进价、卖价、运费、亏损），
  用 number 会显得像「价格从 10 变成 30」，换成 bars 更准。
