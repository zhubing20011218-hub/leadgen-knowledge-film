# 01 · 需求访谈（六问，一次问完）

> 原则：**问"事实"，不问"感觉"**。用户判断不了风格，但说得清自己的处境。
> 一次说完这六个问题（不要一条条挤），拿到答案就写 `brief.json` 跑校验。

## 开场话术（直接发给用户）

```
做这条片，我需要知道 6 件事，你一次回我就行：
1）给谁看：被裁的 / 想转行的 / 宝妈 / 应届生 / 同行，选一个（不确定就说"想转行但没头绪的人"）
2）他现在的处境，用你自己的话说三句：大概什么年龄、原来做什么、发生了什么
3）你手上能拿出的真实证据：自己的店、订单截图、成本结构、走过的弯路，能说几条说几条
4）你想让他看完做什么：去主页看合集 / 评论区问 / 收藏（不放联系方式）
5）要多长：30 秒（默认）/ 60 / 90 秒
6）有没有不能出现的说法：收入数字、品牌名、绝对化用语
```

## 每问的追问与反例

### 问 1 · 给谁看

| 用户答 | 追问 | 为什么 |
|---|---|---|
| "所有人" | 「那你最希望哪一类人来问你怎么做？」 | 定位决定钩子，泛话题没人停下来 |
| "想做跨境的" | 「他现在做什么工作？为什么还没开始？」 | 找到"卡在哪"才有共鸣 |
| "大学生" | 「他最大的顾虑是什么：没本钱、没经验、还是家里反对？」 | 不同顾虑要用不同证据 |

### 问 2 · 处境（**必须问，不许默认**）

要三句具体的话，不要形容词。追问方式：

- 「具体一点：多大年纪、原来是做什么的、哪一年开始的？」——这几项决定钩子的画面（工位、通知、简历）。
- 允许"我朋友/我学员"的真实处境，但**片子里不点名、不说"我的学员月入多少"**。

反例（不要接受）："就是很迷茫很焦虑" → 追问："什么事让他突然发现不行了？"

### 问 3 · 证据（决定这条片有没有说服力）

按可信度排：**自己的订单/后台截图 > 自己的成本和流程 > 公开规则原文 > 自己走的弯路**。
一定要问："有没有具体的数字？进价、运费、佣金、退货率、客单价，随便一个都行。"

- 没有数字 → 这条片改成"讲流程/讲坑"，不硬上百分比。
- 只有别人的数据 → 不用，或者用公开规则（并给出去处）。

### 问 4 · 下一步做什么

默认是"主页看合集"。注意：**平台不允许在视频里放联系方式**（微信/QQ/手机号），也不要写"私信我发资料"这种话术太硬的说法，用"主页有合集""评论区聊"。

### 问 5 · 时长

- 30 秒：只讲一条主线，最通用；
- 60 秒：把"分叉"和"收窄"各拆两段，能多举一个例子；
- 90 秒：再加一段"我自己的弯路/真实数据"，转化最高，但要求证据够。

### 问 6 · 禁用说法

默认全按 `06-合规红线.md`：不出现收入承诺、不出现"最/第一/永久"、不出现别人的品牌名、不做疗效类表述。

## 答案不合格时的处理

| 情况 | 处理 |
|---|---|
| 问 2 答不出 | 这条片不做，先聊清楚；或者改做"通用盘点"型（角度 B），不需要个人处境 |
| 问 3 一条证据都没有 | 改成"讲规则/讲坑"，事实来自公开规则并标注出处 |
| 问 4 想要"直接留微信" | 说明平台限制，改成"主页合集"，并提醒可以做一条"合集"视频承接 |
| 问 6 坚持要写"月入三万" | 不写进片子；改写成成本结构或流程（这也是他们的真实卖点） |

## 收尾

把 6 个答案写成 `brief.json`：

```json
{
  "angle": "laid-off",              // laid-off | pivot-list | ai-ecommerce | own-mistake
  "audience": "30-40 岁被裁、想转行但没头绪的人",
  "pain": ["38 岁", "做了十年工厂管理", "厂子搬到东南亚，他被优化"],
  "proof": [
    "自己在 TikTok Shop 马来西亚站开店，有后台订单截图",
    "一对雨刮进价 10 元、卖 30 元，运费 8 元/公斤",
    "第一年因为没算运费，亏了两万"
  ],
  "cta": "主页看合集",
  "seconds": 30,
  "mood": "cold",
  "banned": ["月入", "稳赚", "包教包会"]
}
```

跑：`python3 scripts/validate_brief.py examples/01-被裁之后/brief.json` —— 过了才进第 1 步（定角度）。
