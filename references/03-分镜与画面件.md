# 03 · 分镜与画面件

## 故事板格式（每一行一句话，不许省）

| 小节 | 字幕（≤18 字，{金} 或 {!红}） | 屏上件 | 件参数 | 备注 |
|---|---|---|---|---|
| 0–1 | 毕业那年，我们都以为路只有一条 | 时间线 | 3 个节点依次亮 | |
| 1–2 | 读书、上班、结婚、退休 | 时间线 | 节点推进 | |
| 2–3 | 没人说，这条路中间会断 | 时间线 | 整条线抖动一下 | |
| 3–4 | 38 岁这年，厂子搬走了 | 断裂卡 | 一纸通知落桌 | |
| 4–5 | （片名卡，无字幕） | 片名卡 | 《被裁之后》 | |
| …

规则：
- **一句一件事**，≤18 字；说话不要"总之、其实、所以说"；
- 屏上必须有一个对应动作；说到数字，屏上就要有那个数字；
- 每 2 小节至少换一次画面元素；同一个件最多连用 3 句。

## 件的接口（照这个写，才能复用）

```js
CH.piece = function (fr, t, p) {
  const a = p.a == null ? 1 : p.a;        // 进出场由故事板乘
  if (a <= 0.003) return;
  fr.g({ a }, () => { /* 只画这一件；坐标相对 p */ });
};
```
三条纪律：件不自己管时间、不画字幕、写完在注释里写「x 范围 / y 范围」（越界检查要用）。

## 安全区（竖屏 1080×1920）

- x 60–1020；y 150–1520（1520 以下是字幕区）；
- 大字 `align:'c'`、`x=540`；右对齐数字 `align:'r'`、`x=960`；
- 写文字前先 `fr.measure` 量宽，超 900 就减字号。

## 字幕

- 逐字由虚变实，`size 56`，一行最多 930px；超了先缩字号（56→42），再按逗号折两行；
- 关键词染金（钱/结论）、负面词染红（被吃掉/失去），**一句最多染一处**。
