# 03 · 分镜：只写 film.json

> 画面由技能自带的 15 个「件」和 28 个图标画，**模型只写一份 film.json**（字幕 + 每一镜用哪个件、填什么字），不写画面代码。
> 这样换哪个模型（包括 DeepSeek）出片都稳，排版错、字压字、越界这类毛病由件本身管住。
> 版式照标杆样片：顶栏「• 01 章名 …… 05 / 14」+ 进度线，章节小标「— 01 ENGLISH」，中间一个主画面，
> 底部一行粗字幕（左边一条章节色竖线、关键词染章节色），最下面 15% 留给平台界面。

## 节奏：一句字幕 = 一小节

| 速度 | 一句 | 30 秒 | 60 秒 | 90 秒 |
|---|---|---|---|---|
| 112.8 BPM（默认，和标杆样片那首 BGM 同速） | 2.13 秒 | 14 句 | 28 句 | 42 句 |
| 128 BPM（紧张） | 1.88 秒 | 16 句 | 32 句 | 48 句 |
| 100 BPM（舒缓） | 2.40 秒 | 12–13 句 | 25 句 | 37–38 句 |

画面的每一次变化都落在拍子（鼓点）上——这是教程第 02 条「画面每变一次，都落在重拍上」：
新的一镜在它第一句的第 1 拍进场；同一镜里每多一句就往上加一样东西，而且**这一样东西拆到这一小节的四拍上**（一拍一动）：
第 1 拍条目 / 名字出现 → 第 2 拍它的数、打勾、金额落下 → 第 3 拍补充小字、盖章 → 第 4 拍这一条闪一下。每一步 0.15–0.25 秒内到位，压在鼓点上。
件都已经这样排好了，写 film.json 不用管拍子。11-18 逐帧量：标杆样片画面变化四拍都有（第 1–4 拍 28 / 20 / 17 / 18 次）；
我们改之前一小节只在第 1 拍变一次（30 秒 14 次、57% 在拍上），改之后 32 次、97% 在拍上，第 1–4 拍 12 / 8 / 5 / 6 次。

## film.json 的格式

```json
{
  "title": "被裁之后",
  "bpm": 112,
  "chapters": [
    {
      "name": "价格战", "key": "价格战", "en": "Price War", "color": "red",
      "pics": ["大数字 199", "199 掉成 59", "59 掉成 39", "盖章 白干"],
      "shot": { "type": "number", "head": "同一个款 三年时间", "values": [199, 59, 39], "prefix": "¥", "units": ["三年前", "去年", "今天"],
                "stamp": { "text": "白干" }, "note": "示例" },
      "lines": [
        { "text": "三年前 这个款卖199", "hl": ["199"] },
        { "text": "去年 掉到59", "hl": ["59"] },
        { "text": "今天 只卖39", "hl": ["39"] },
        { "text": "扣完运费 等于白干", "hl": ["白干"] }
      ]
    }
  ]
}
```

上面例子里的数（199、59、39）是标杆样片的，只为演示格式；写片时数字一律来自 brief，检查会拦下 brief 里没有的数。

| 字段 | 规矩 |
|---|---|
| `title` | 片名，也是成片的文件名和封面上的大字（超过 6 个字封面上拆两行） |
| `post` | 发布文案：`{"title": 发布标题 ≤ 30 字, "tags": 3–5 个话题（不带 #）, "cover": 封面第二行小字 ≤ 10 字（可不写）}`。和字幕一样不许联系方式、收入承诺、编数字 |
| `bpm` | 112 / 128 / 100，按 brief 的 mood |
| `chapters[].name` | 章名，2–4 个字，显示在顶栏 |
| `chapters[].pics` | 写给自己看、不上屏，**写在 lines 前面**：这章每一句画面上多出来的那一条，一句一条。先列它，再挑件、写字幕 |
| `chapters[].shot` | **这章的画面**（用哪个件、填什么），写在 lines 前面。整章一个画面，句子一句往前走一步 |
| `chapters[].key` | **这章的大关键词**，2–5 个字（如「价格战」「三把锁」「换个市场」），整章顶在画面上方的大字，观众看完记住的就是它。大字卡（title / statement）独占的章可以不写 |
| `chapters[].en` | 章节英文小标，2–3 个词（如 `PRICE WAR`），只做装饰，不许出现中文 |
| `chapters[].color` | `red` `amber` `violet` `cyan` `green` `pink` `blue` 之一。相邻两章不同色；红 = 失去 / 代价，绿 = 出路 / 结果，全片不破例 |
| `chapters[].turn` | 可选，`true` 标反转那一章：配乐在它前一小节撤鼓，它的第一拍全编制回来 |
| `lines[].text` | 字幕，**不带任何标点**（停顿用一个空格），一句 ≤ 16 个字，一句只说一件事 |
| `lines[].hl` | 0–2 个关键词，必须原样出现在 text 里，会染成章节色 |
| `lines[].shot` | 少用：这一句在章里开第二个画面（章上的画面实在装不下这句时）。不写 = 同一镜往前走一步 |
| `lines[].note` / `shot.note` | 出处小字。屏上有数字的镜必须写：真实来源写「来源：作者店铺后台 2025」；从 brief 算出来的写「按 … 算」；brief 是 example 的写「示例」；人生节点的年龄写「示意」。**图表里的数不许用「示意」糊过去**：拿不出依据就别放数字 |
| `shot.head` | 可选，一镜的小标题（如「同一个款 三年时间」），≤ 12 字；有 key 时显示在 key 下面一行小字 |
| `shot.stamp` | 可选，任何有画面的件都能加：`{"text": "白干"}` 在这一镜最后一句砸一个 2–5 字的红章（那句还要出最后一条时，先出条目、第三拍再砸章）。章是这一段的结论，只盖在最后一句；给结论 / 情绪落点那一句一个画面，也算这一镜的一步 |

## 15 个件

「一句一步」的意思是：这一镜有几句，就分几次出场；东西比句子多，多出来的挤在最后一句里按拍子出。

| type | 用来演 | 字段 | 一句一步怎么走 |
|---|---|---|---|
| `title` | 片名卡（左对齐，全片最大的字） | `kicker`（英文小标）、`top`、**`big`**（2–4 字）、`bottom` | 第一句砸下来，之后停住 |
| `statement` | 提问、结论、片尾 —— 不配画的句子 | `top`、**`big`**（2–6 字）、`sub` | 一次出完 |
| `number` | 一个数从 A 变到 B（价格战、亏了多少） | **`values`**（1–4 个数）、`prefix`（¥ $）、`suffix`（几个值单位不同时写成列表，一个值一个：`["万", ""]`，prefix 也一样）、`units`（每个值后面的小字，如「三年前」「今天」）、`from`（从几开始滚）、`bar`（`{label, pct, tag}` 下面一条占比） | 一句换下一个值，旧值留虚影 |
| `bars` | 几样东西比大小 | **`rows`**（2–6 个 `{label, value, tag}`，tag 是条下面的一句补充，不是单位）、`unit`（数字后面的单位）、`max` | 一句亮一条。**每条的数都要是字幕里说到的**，没有数可比就用 cards |
| `ledger` | 算一笔账：卖价减进价减运费，剩多少 | **`rows`**（2–5 个 `{label, value, op}`，`value` 写数字，减的写 `"op": "-"`）、`prefix`（¥ $）、`suffix`、`total`（合计那行的字，如「一对赚」） | 一句记一笔（加的绿、减的红）；写了 total 再多一句，合计**由程序算出来**（不用自己算，也编不出来） |
| `ring` | 一个占比 + 几条原因 | **`value`**（0–100）、`suffix`、`label`、`rows`（0–5 个 `{text, tag}`） | 环先转满，再一句点一条原因 |
| `timeline` | 人生节点、时间顺序 | **`nodes`**（2–5 个 `{label, sub}`）、`breakAt`（在第几个节点后断，从 0 数）、`breakStep`（第几句断，从 0 数） | 一镜一句：节点按拍子一口气亮完；一镜几句：一句亮一个节点。breakStep 那句裂开，后面的节点变灰 |
| `fork` | 几条路 → 只剩一条（或一条都不剩） | **`paths`**（2–5 个 `{label, sub}`，5 条时标签用 2–3 个字）、`pick`（留下来、能走的那条，从 0 数；几条全是死路写 `-1`） | 第一句路长出来，之后每句划掉一条，最后一句点亮 pick（n 条路最多撑 n+1 句）。**pick 不能是死路**（检查会拦） |
| `fork` + `focus` | 逐条讲几条路（"考公要…""转销售要…"） | 同上，加 `focus`（这句讲的那条，从 0 数），不写 pick | 一次出完：这一条亮、其他变暗、它的 sub 在下面放大。每句一镜，paths 每镜都写同一份，只改 focus |
| `compare` | 同一样东西的两种情况（国内 / 海外、以前 / 现在） | **`left`**、**`right`**（各 `{label, value, sub}`）、`badge`（`{label, value}`） | 第一句出左边，第二句箭头过去出右边；一镜三句以上时角标单独占第三句（有角标最多撑 3 句） |
| `checklist` | 条件、要什么不要什么 | `title`、**`rows`**（1–6 个 `{text, ok, note}`，`ok: false` 画横线发灰） | 一句勾一条 |
| `steps` | 下一步怎么做（01 02 03） | **`rows`**（1–5 个 `{text, note}`，编号自动画，note 写一句补充，不写编号） | 一句出一步 |
| `cycle` | 飞轮、循环、互相带动 | `center`、**`nodes`**（3–6 个 `{label, sub}`） | 一句亮一个节点 |
| `cards` | 几个平台 / 选项摆在一起 | **`items`**（2–6 个 `{name, tag, rows, icon}`）、`pick` | 一句亮一张 |
| `object` | **一样认得出的东西**：一张床、一部手机、一个工位；或者一大堆（30 份简历） | **`icon`**、`label`、`sub`、`count`（≥ 2，写了就画一片并数数；超过 60 只画 60 个，数字照样数到真实数量）、`unit`（数字后的字，如「份」）、`state`（`no` 盖红杠 / `ok` 打勾） | 一次出完，一堆的话一个个冒出来 |
| `flow` | 从 A 到 B：工厂搬去越南、货从国内发到海外 | **`from`**、**`to`**（各 `{icon, label, sub}`）、`via`（`{icon, label}`，路上走的东西，如轮船） | 第一句出 A，第二句（只有一句就第三拍）沿弧线走到 B |

粗体是必填。件里的字也不要标点（数字里的小数点、¥ $ % 可以）。

### 图标（让观众一眼认出"这是什么"）

`object`、`flow` 必须用图标；`checklist` 的 rows、`cards` 的 items、`cycle` 的 nodes、`compare` 的 left / right、`timeline` 的 nodes 都可以加 `"icon"`。
只能用下面这些名字（写别的检查会报错）：

| 名字 | 是什么 | 名字 | 是什么 | 名字 | 是什么 |
|---|---|---|---|---|---|
| `phone` | 手机 | `laptop` | 笔记本电脑 | `resume` | 简历 / 文件 |
| `person` | 一个人 | `people` | 一群人 / 用户 | `bed` | 床（累了、躺平） |
| `desk` | 工位 / 上班 | `briefcase` | 公文包 / 工作 | `factory` | 工厂 |
| `store` | 店铺 | `house` | 房子 / 房贷 | `box` | 包裹 / 货 |
| `ship` | 轮船 / 海运 | `plane` | 飞机 / 空运 | `globe` | 地球 / 海外 |
| `money` | 钞票 | `coins` | 硬币 / 成本 | `cart` | 购物车 / 下单 |
| `chartup` | 上涨 | `chartdown` | 下跌 | `clock` | 时间 |
| `calendar` | 日期 / 每天 | `chat` | 聊天 / 评论 | `video` | 视频 / 内容 |
| `ai` | AI | `chair` | 椅子 / 店里的家当 | `cup` | 奶茶 / 饮品 |
| `bowl` | 碗筷 / 吃饭 / 餐饮 | | | | |

**字幕里说到一样看得见的东西（床、简历、工位、手机、包裹、工厂），这一镜就该有它的图标**——看图评审最常挑的毛病就是"遮住字幕看不出在演什么"。

## 怎么选件（照着查，不要硬凑）

| 这句话在说 | 用 |
|---|---|
| 一个人一生 / 一段经历的几个时间点 | `timeline` |
| 一件事被打断 | `timeline` 的 `breakAt` + `breakStep` |
| 摆出几个选择，最后只剩一个（或全是死路） | `fork`（全是死路 `"pick": -1`） |
| 一条一条讲几个选择 | `fork` + `focus`（每句一镜，别每句重开一个划线的 fork，前后会对不上） |
| 一个价格 / 金额 / 数量变了 | `number` |
| 钱 / 时间被吃掉了多少，被谁吃掉 | `ring` 或 `number` + `bar` |
| 几样东西比大小 | `bars` |
| 一笔一笔算账（进价、运费、佣金吃掉了多少） | `ledger` |
| 同一样东西换个地方 / 时间就不一样 | `compare` |
| 需要什么、不需要什么 | `checklist` |
| 几个东西互相带动 | `cycle` |
| 几个平台 / 渠道 | `cards` |
| 下一步做什么 | `steps` |
| 说到一样看得见的东西（"只想躺着""投了几十份简历""换的只是工位"） | `object`（一堆就写 `count`） |
| 从一处到另一处（"厂子搬去了越南""货发到海外"） | `flow` |
| 片名 | `title` |
| 提问、结论、金句、片尾 | `statement` |

## 画面先行（最重要的一条）

标杆样片 90 秒 42 句只有 12 个画面，一个画面平均撑 3.5 句，每句都往上加一样东西（¥199 → 59 → 39 → 盖「白干」；40% 的环下面一条条亮出三把锁）。
上游项目的规矩也是「一个场景撑 2–5 句，每句只改一处；画不出来的句子，改句子」。做法是**先定画面，再让句子跟着画面写**，每章照四步：

顺序就是 film.json 里一章的字段顺序：`key` → `pics` → `shot` → `lines`。

1. **key**：这章的大关键词，2–5 个字。
2. **一个画面**（章上的 `shot`）：照下面「怎么选件」挑一个件，条目一次写好——这章有几句，就写几条（stamp 也算一条）。
   动笔前先在 `pics` 里列出每句多出来的那一条；几条说的是不同的事（换了市场、上了 40 个商品、开张一单 9.9 美元），
   就用能一条一件事的件（`steps` `checklist` `cards`，条目里可以写数），别拿只有两格的 `compare` 去装。
3. **再写字幕**：第 k 句说的就是第 k 条。字幕里说的数，这一镜画面上必须有（检查会拦）。
4. **演不了的句子**：先换个说法，让它说画面上有的东西；还不行，才在这章里开第二镜。

**件要换着用**：`steps` / `checklist` 只是一行行字，全片最多用 2 次（片尾的「下一步」用 steps 正合适），其余章用有形象的件——有数用 `number` `bars` `ring` `ledger`，几条路用 `fork`，几样东西用 `cards` `object`，从 A 到 B 用 `flow`。

全片画面数 ≤ 句数的一半（逐条讲同一组岔路算一个画面）；画面不动的句子（停顿句）≤ 1/5，只给提问、结论，不许说数字。检查脚本按这两条拦。

规矩：
1. **字幕没说的不往画面上加**；第 k 条 = 第 k 句。不要一句换一个画面，也不要几句对不上一个画面。
2. 开头 3 句就要让人停下：第一镜用 `title`、`timeline`、`number`、`compare` 或 `object`，不要用空洞的 `statement`。
3. `statement` 全片最多占三分之一，它没有画面。
4. 片尾最后一句落到 brief 的 cta（「主页看合集」「评论区聊」），不出现联系方式。
5. 每个数字都来自 brief 的 proof 或公开规则；brief 写了 `example: true` 的，note 一律写「示例」。
