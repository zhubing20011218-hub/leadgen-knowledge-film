# 03 · 分镜：只写 film.json

> 画面由技能自带的 12 个「件」画，**模型只写一份 film.json**（字幕 + 每一镜用哪个件、填什么字），不写画面代码。
> 这样换哪个模型（包括 DeepSeek）出片都稳，排版错、字压字、越界这类毛病由件本身管住。
> 版式照标杆样片：顶栏「• 01 章名 …… 05 / 14」+ 进度线，章节小标「— 01 ENGLISH」，中间一个主画面，
> 底部一行粗字幕（左边一条章节色竖线、关键词染章节色），最下面 15% 留给平台界面。

## 节奏：一句字幕 = 一小节

| 速度 | 一句 | 30 秒 | 60 秒 | 90 秒 |
|---|---|---|---|---|
| 112 BPM（默认，和标杆样片同速） | 2.14 秒 | 14 句 | 28 句 | 42 句 |
| 128 BPM（紧张） | 1.88 秒 | 16 句 | 32 句 | 48 句 |
| 100 BPM（舒缓） | 2.40 秒 | 12–13 句 | 25 句 | 37–38 句 |

画面的每一次变化都落在小节线（重拍）上：新的一镜在它第一句开始时进场，同一镜里每多一句就往上加一样东西。

## film.json 的格式

```json
{
  "title": "被裁之后",
  "bpm": 112,
  "chapters": [
    {
      "name": "人生", "en": "Life Plan", "color": "violet",
      "lines": [
        { "text": "我们都被教过同一条路", "hl": ["同一条路"],
          "shot": { "type": "timeline", "nodes": [{"label": "毕业", "sub": "22"}, {"label": "入职", "sub": "24"}, {"label": "结婚", "sub": "30"}], "breakAt": 1, "breakStep": 1 },
          "note": "人生节点为示意" },
        { "text": "直到有一天 路断了", "hl": ["路断了"] }
      ]
    }
  ]
}
```

| 字段 | 规矩 |
|---|---|
| `title` | 片名，也是成片的文件名 |
| `bpm` | 112 / 128 / 100，按 brief 的 mood |
| `chapters[].name` | 章名，2–4 个字，显示在顶栏 |
| `chapters[].en` | 章节英文小标，2–3 个词（如 `PRICE WAR`），只做装饰，不许出现中文 |
| `chapters[].color` | `red` `amber` `violet` `cyan` `green` `pink` `blue` 之一。相邻两章不同色；红 = 失去 / 代价，绿 = 出路 / 结果，全片不破例 |
| `chapters[].turn` | 可选，`true` 标反转那一章：配乐在它前一小节撤鼓，它的第一拍全编制回来 |
| `lines[].text` | 字幕，**不带任何标点**（停顿用一个空格），一句 ≤ 16 个字，一句只说一件事 |
| `lines[].hl` | 0–2 个关键词，必须原样出现在 text 里，会染成章节色 |
| `lines[].shot` | 这一句开一个新镜；不写 = 同一镜往前走一步。**每章第一句必须有 shot** |
| `lines[].note` / `shot.note` | 出处小字。屏上有数字的镜必须写：真实来源写来源（「作者店铺后台 2025」）；编的写「示例」；示意写「示意」 |
| `shot.head` | 可选，一镜的小标题（如「同一个款 三年时间」），≤ 12 字 |

## 12 个件

「一句一步」的意思是：这一镜有几句，就分几次出场；东西比句子多，多出来的挤在最后一句里按拍子出。

| type | 用来演 | 字段 | 一句一步怎么走 |
|---|---|---|---|
| `title` | 片名卡（左对齐，全片最大的字） | `kicker`（英文小标）、`top`、**`big`**（2–4 字）、`bottom` | 第一句砸下来，之后停住 |
| `statement` | 提问、结论、片尾 —— 不配画的句子 | `top`、**`big`**（2–6 字）、`sub` | 一次出完 |
| `number` | 一个数从 A 变到 B（价格战、亏了多少） | **`values`**（1–4 个数）、`prefix`（¥ $）、`suffix`、`units`（每个值后面的小字，如「三年前」「今天」）、`from`（从几开始滚）、`bar`（`{label, pct, tag}` 下面一条占比） | 一句换下一个值，旧值留虚影 |
| `bars` | 几样东西比大小 | **`rows`**（2–6 个 `{label, value, tag}`，tag 是条下面的一句补充，不是单位）、`unit`（数字后面的单位）、`max` | 一句亮一条 |
| `ring` | 一个占比 + 几条原因 | **`value`**（0–100）、`suffix`、`label`、`rows`（0–5 个 `{text, tag}`） | 环先转满，再一句点一条原因 |
| `timeline` | 人生节点、时间顺序 | **`nodes`**（2–5 个 `{label, sub}`）、`breakAt`（在第几个节点后断，从 0 数）、`breakStep`（第几句断，从 0 数） | 第一句节点按拍子亮；breakStep 那句裂开，后面的节点变灰 |
| `fork` | 几条路 → 只剩一条 | **`paths`**（2–4 个 `{label, sub}`）、`pick`（留下的那条，从 0 数） | 第一句路长出来，之后每句划掉一条，最后一句点亮 pick |
| `compare` | 同一样东西的两种情况（国内 / 海外、以前 / 现在） | **`left`**、**`right`**（各 `{label, value, sub}`）、`badge`（`{label, value}`） | 第一句出左边，第二句箭头过去出右边和角标 |
| `checklist` | 条件、要什么不要什么 | `title`、**`rows`**（1–6 个 `{text, ok, note}`，`ok: false` 画横线发灰） | 一句勾一条 |
| `steps` | 下一步怎么做（01 02 03） | **`rows`**（1–5 个 `{text, note}`，编号自动画，note 写一句补充，不写编号） | 一句出一步 |
| `cycle` | 飞轮、循环、互相带动 | `center`、**`nodes`**（3–6 个 `{label, sub}`） | 一句亮一个节点 |
| `cards` | 几个平台 / 选项摆在一起 | **`items`**（2–6 个 `{name, tag, rows}`）、`pick` | 一句亮一张 |

粗体是必填。件里的字也不要标点（数字里的小数点、¥ $ % 可以）。

## 怎么选件（照着查，不要硬凑）

| 这句话在说 | 用 |
|---|---|
| 一个人一生 / 一段经历的几个时间点 | `timeline` |
| 一件事被打断 | `timeline` 的 `breakAt` + `breakStep` |
| 摆出几个选择，最后只剩一个 | `fork` |
| 一个价格 / 金额 / 数量变了 | `number` |
| 钱 / 时间被吃掉了多少，被谁吃掉 | `ring` 或 `number` + `bar` |
| 几样东西比大小 | `bars` |
| 同一样东西换个地方 / 时间就不一样 | `compare` |
| 需要什么、不需要什么 | `checklist` |
| 几个东西互相带动 | `cycle` |
| 几个平台 / 渠道 | `cards` |
| 下一步做什么 | `steps` |
| 片名 | `title` |
| 提问、结论、金句、片尾 | `statement` |

规矩：
1. **一章一个主画面，撑 2–4 句，一句只加一样东西。** 不要一句换一个镜。
2. 开头 3 句就要让人停下：第一镜用 `title`、`timeline`、`number` 或 `compare`，不要用空洞的 `statement`。
3. `statement` 全片最多占三分之一，它没有画面。
4. 片尾最后一句落到 brief 的 cta（「主页看合集」「评论区聊」），不出现联系方式。
5. 每个数字都来自 brief 的 proof 或公开规则；brief 写了 `example: true` 的，note 一律写「示例」。

## 写新件

12 个件不够用时，在 `template/scenes.js` 里照现成的写一个函数（只用 `c.lt / c.step / c.st` 算动画，不用 `Math.random`，内容放在 y 400–1400），
再在上面的件表和 `scripts/check_film.py` 的 `TYPES` 里各登记一行。先用 `bash scripts/build.sh <工程> --sheet-only` 看图，再出全片。
