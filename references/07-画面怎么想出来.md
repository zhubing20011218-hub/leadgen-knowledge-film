# 07 · 画面怎么想出来

用这个技能的人讲什么题目，事先猜不到：外卖骑手、考公、宝妈副业、健身、跨境物流、开奶茶店……
所以这里不给一份"能用哪些画面"的清单，给的是**怎么从一句话想出画面**的方法。
现成的 15 个件（references/03）是常见句型的捷径；件装不下的，用自由画面 `draw` 自己搭（字段在本页最后）。
图标也不只 28 个：自带的霓虹图标之外，还有 Lucide 图标库 1500 多个，`python3 scripts/find_icon.py 快递` 按中文或英文找。

## 一、画面为什么要有

这种片子没有人声。观众一句字幕只读 2 秒，**画面的活是让他在这 2 秒里"看见"这句话**：

- 句子里说到的东西，屏上认得出（说"直播间"，屏上是一部手机、里面是直播间）；
- 句子里的动作，屏上真的发生（说"掉到 39"，那个数真的往下掉；说"没人回"，那条消息真的晾在那）；
- 观众因此明白了一件事，和上一句明白的不一样。

做到了叫**讲解**；只是给句子配一个好看的东西，叫**配图**。判断办法：把这个画面换给另一段文案，还成立吗？成立，就是配图，要重想。

三种句子**不配新画面**，画面停住就好（全片约五分之一）：提问（"为什么？"）、结论（"白干"——可以盖个章）、情绪停顿（"那一刻我懂了"）。

## 二、怎么想出来：四步

### 1. 拆句子：东西 + 动作

先把一句话拆成**名词**（屏上要有的东西）和**动词**（屏上要发生的事）。

| 字幕 | 东西 | 动作 |
|---|---|---|
| 开播两小时 在线只有三个人 | 手机直播间、在线人数 | 人数停在 3（甚至往下掉） |
| 货从义乌走到买家手里要十五天 | 仓库、飞机、买家的家 | 一条线从仓库走到家，标上天数 |
| 进来二十个人 只有一个下单 | 一群人 | 二十个里亮起一个 |
| 退一单 运费比货还贵 | 一张退货单 | 运费那一行比货价那一行大，划掉利润 |

句子里**没有东西**的（"你要想清楚""这很重要"），多半是该删的议论，或者属于上面"不配新画面"那三种。

### 2. 给每样东西找一个观众认得的样子

按顺序问，前面的有答案就不往后问：

1. **它本身是个东西吗？** 是就画它本身：手机、包裹、仓库、简历、外卖车、奶茶。屏上是一个**认得出的物件**，不是一个写着名字的圆圈。
2. **它是线上发生的事吗？**（下单、私信、评论、直播、后台数据）画进**手机**里：`phone`，里面是列表或聊天气泡。观众每天看手机，一眼就懂。
3. **它是一个数、一个量吗？** 给它一个看得见的大小：一个会跳的大数字（`num`）、一根会走的进度条（`bar`）、一群人里亮几个（`crowd`）。
4. **它是一个比例、"多少个里有几个"吗？** 用 `crowd`：画出全部，再点亮那几个。"一百个里一个"比"1%"有冲击力。
5. **它是一个过程、一条路吗？** 摆成一排站点，用箭头连起来（`arrow`），一拍走一站。
6. **它是一张单据、一条规则、一段对话吗？** 用卡片（`box`）：标题 + 一行行写出来，像收据、通知、聊天记录、规则卡。
7. **都不是**（一个判断、一个态度）——不画，上大字（`statement`），或者让已经在屏上的东西被划掉 / 打勾 / 盖章。

找到以后再问一句：**观众在生活里哪儿见过它？** 外卖 App、快递单、工资条、微信群、日历、计算器、排队……拴在他见过的东西上，他才记得住。

### 3. 让动词真的发生

| 字幕里的动词 | 屏上的动作（`acts`） |
|---|---|
| 涨、多了、翻倍 / 掉、少了、只剩 | `count` 数字变过去（往下掉配一声闷响）；`grow` 放大 |
| 没了、失败、不行、被拒 | `strike` 划掉、`cross` 打叉，然后 `dim` 变暗 |
| 成了、通过、选中、对的 | `check` 打勾、`color` 变绿、`grow` 放大一下 |
| 去、到、送到、转给 | `arrow` 连过去，或 `move` 把它挪过去 |
| 越来越少、耗光、等不及 | `fill` 进度条往回走 |
| 只有几个、筛出来 | `mark` 一群里亮起几个 |
| 冷清、被忽略 | `dim` 整个暗下去 |
| 崩了、慌了、被催 | `shake` 抖一下 |
| 变成、换成 | `swap` 换字 |
| 重点、注意 | `flash` 闪一下 |

### 4. 一镜撑几句，每句只加一样

一章一个画面，撑 2–5 句。第一句把主体摆出来，**后面每一句只在它上面加一样东西、或者对它做一个动作**——不要每句换一个新东西。
观众看着同一个画面一步步变化，比看一页页 PPT 好懂得多。写法就是 `items` 和 `acts` 的 `at`：第几句出来、第几句做什么。

## 三、画成什么样

- **一个主体，往大了画。** 主体占内容区宽度六七成（手机 `size` 0.45–0.55，一排三个图标各 0.24–0.28）。东西太小、挤在一角，是最常见的毛病。
- **一镜最多 3–5 样东西。** 东西多了观众不知道看哪；`items` 上限 10 是给 `crowd` 之外的少数情况留的。
- **字是标签，不是句子。** 句子在字幕里。画面上的字 ≤ 10 个（`text`），图标下面的标签 ≤ 8 个，卡片一行 ≤ 12 个。
- **颜色只表达一件事。** `main` 这一章的重点（默认）；`red` 损失、错、代价；`green` 结果、对、出路；`gold` 钱、亮点；`dim` 背景里的、不重要的。一章里别超过两种颜色。
- **数字要大。** 重要的数用 `num`（默认最大号），不要塞在一行小字里。
- **常用的六种摆法**（x、y 是内容区里的比例，0 左上 → 1 右下）：

| 摆法 | 适合 | 位置 |
|---|---|---|
| 一个大主体 + 旁边一个数 | 一样东西和它的状态（直播间 + 在线人数） | 主体 x 0.3 y 0.5（size 0.5）；数 x 0.78 y 0.25；补充 x 0.78 y 0.65 |
| 一排三站 + 箭头 | 过程、路线、从 A 到 B | 三样 y 0.25，x 0.15 / 0.5 / 0.85；下面 y 0.7 放一根进度条或一个数 |
| 左右对照 | 同一件事两种情况（以前 / 现在、别人 / 我） | 左 x 0.27，右 x 0.73，同一个 y；最后一句在中间下面盖结论 |
| 上下因果 | 因为上面这个，所以下面那个 | 上 y 0.25，下 y 0.75，中间一个向下的箭头 |
| 一群里标几个 | 比例、转化、筛选 | `crowd` x 0.5 y 0.3；下面 y 0.75 一张卡片或一个数 |
| 手机里发生 | 线上的事：私信、下单、直播、评论、后台 | `phone` x 0.5 y 0.5 size 0.5；或者偏左 x 0.3，右边放数字 |

不写 x、y 就自动排：一行三个，多了排成格子。自动排不会压在一起，但不一定好看；主体明确的画面自己摆。

## 四、怎么动：一拍一动

一句字幕 = 一小节 = 四拍（references/04）。画面的每次变化都落在拍子上：

- **第 1 拍**：这句的东西出现（`at` = 第几句，`beat` 不写就是 1）；
- **第 2 拍**：它的数、状态落下（数字落定、打勾、进度条走到位）——`beat: 2`；
- **第 3 拍**：补充（标签、第二样东西、划掉）——`beat: 3`；
- **第 4 拍**：强调（闪一下、抖一下）——`beat: 4`。

不用每拍都写满；但**每句至少有一个变化**（出场或动作），否则这句画面不动，只能留给提问和结论。
卡片和手机里的行会自己一拍一行写出来；一群人会分四拍冒出来；配乐也按这些时刻自动配音（references/04「画面动作 → 音乐」）。

## 五、每一镜过三问

写完、出拼图以后，每一镜问：

1. **屏上这是什么？** 用一个日常的词回答（一部手机、一张退货单、一群人、一条路线）。遮住字幕还认得出。答案是"几个圈""一些线""一行字"的，重想。
2. **它在干什么？** 用一个动词回答，就是字幕里的那个动词。
3. **观众因此明白了什么？** 一句话，和上一镜不一样。

再做两个测试：**遮字幕**——只看画面，猜得出在讲什么吗？**换文案**——这个画面换给别的题目也成立吗？成立就是配图。

## 六、现成的件还是自己画？

| 这一章演的是 | 先用 |
|---|---|
| 一个数在变（价格、收入、人数） | `number` |
| 一笔笔算账 | `ledger` |
| 几条路选一条 / 全是死路 | `fork` |
| 同一件事两种情况 | `compare` |
| 人生节点、时间线、某一步断了 | `timeline` |
| 几样东西比大小 | `bars` |
| 打勾清单 / 步骤（全片最多两次） | `checklist` / `steps` |
| **题目里特有的东西和场景**（直播间、外卖单、快递路线、一群顾客、一张通知、一段聊天、一个后台） | **`draw`** |

现成的件排版最稳；它们演不出"这个题目自己的东西"。**一条片至少有一两章用 `draw` 把题目里观众认得的那个场景画出来**——
这是这条片和别的片不一样的地方，也是观众觉得"说的就是我"的地方。

## 七、自由画面 `draw` 的字段

```json
"shot": { "type": "draw", "note": "示意",
  "items": [
    { "id": "p", "kind": "phone", "title": "直播间", "live": true, "chat": true, "x": 0.3, "y": 0.5, "size": 0.5, "at": 0,
      "rows": [ { "them": "多少钱" }, { "me": "N 元包邮" } ] },
    { "id": "n", "kind": "num", "value": "N", "suffix": " 人", "label": "在线", "x": 0.78, "y": 0.25, "at": 1 },
    { "id": "e", "kind": "icon", "icon": "eye", "label": "看一眼就走", "x": 0.78, "y": 0.65, "at": 2 }
  ],
  "acts": [
    { "id": "n", "do": "count", "to": "N", "at": 2, "beat": 2 },
    { "id": "e", "do": "cross", "at": 2, "beat": 3 },
    { "id": "p", "do": "dim", "at": 3 }
  ],
  "stamp": "冷场" }
```

（例子里的 N 是占位：写真实的数，只用 brief 里有的。）

**items**：屏上的东西，最多 10 样。每样都有 `kind`、`at`（这一镜第几句出场，从 0 数）；`beat` 第几拍（1–4，默认 1）；`x` `y` 位置（0–1，不写就自动排）；`id`（要被连线或做动作的才写）；`color`（main / alt / red / green / gold / white / dim）。

| kind | 是什么 | 字段 |
|---|---|---|
| `icon` | 一个认得出的东西 | `icon`（图标名，`find_icon.py` 找）、`label`（下面的标签，≤ 8 字）、`size`（宽度比例，默认 0.26） |
| `text` | 一个标签、一个词 | `text`（≤ 10 字）、`size`：s / m / l / xl |
| `num` | 一个大数字（出场时从 0 数上去） | `value`（数字）、`prefix` / `suffix`（¥、元、人、%）、`label`（下面一行小字，第 2 拍出来）、`from`（从几开始数） |
| `box` | 卡片：单据、通知、规则、记录 | `title`（≤ 8 字）、`icon`（标题左边的小图标）、`rows`（一行行，≤ 5 行、每行 ≤ 12 字，一拍写一行）、`w`（宽度比例，默认 0.76） |
| `phone` | 手机 | `title`（顶栏：直播间、订单、消息）、`live`（左上角红色 LIVE）、`rows`（列表）；`chat: true` 时 rows 写成 `{"them": "…"}` / `{"me": "…"}` 两边的气泡；没有 rows 时可以写 `icon` 在屏幕中间；`size` 默认 0.46 |
| `crowd` | 一群人 / 一堆东西 | `n`（一共几个，2–100）、`mark`（一开始亮几个）、`icon`（默认是人，可以换成 package 之类）、`w` |
| `bar` | 一根进度条 | `value`（填满的比例 0–1）、`text`（右边显示的字，比如 30%、满）、`label`（上面的名字）、`w` |
| `arrow` / `line` | 连线（带箭头 / 不带） | `from`、`to`（一样东西的 id，或一个点 [x, y]）、`label`（第 2 拍出来）、`dash`（虚线） |

**acts**：之后对某样东西做什么。每个写 `id`、`do`、`at`（第几句）、`beat`（第几拍）；必须晚于它出场。

| do | 做什么 | 额外字段 |
|---|---|---|
| `strike` / `cross` / `check` | 划掉 / 打叉 / 右上角打勾 | — |
| `count` | 数字变到 | `to` |
| `fill` | 进度条走到 | `to`（0–1）、`text`（右边的字跟着换） |
| `mark` | 一群里亮起几个 | `to` |
| `move` | 挪到 | `x`、`y` |
| `grow` | 放大到几倍 | `s`（默认 1.3） |
| `swap` | 换字（text 的字、icon 的标签） | `text` |
| `color` | 换颜色 | `color` |
| `dim` / `hide` | 变暗 / 收走 | — |
| `flash` / `shake` | 闪一下 / 抖一下 | — |

`check_film.py` 会查：图标有没有（没有会给几个像的）、出界、互相压住、连线两头挨得太近、字太长、画面太小太空、哪句画面不动、字幕说的数画面上有没有、数是不是编的。
