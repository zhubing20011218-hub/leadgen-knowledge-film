# 05 · 检查表（机器 8 条 + 人 3 条）

## 机器（出片前自动跑，任一条不过就退回）

| # | 检查 | 阈值 | 不过怎么办 |
|---|---|---|---|
| 1 | 时长 = 段落表算出的长度（±1 帧） | 30.00 / 60.00 / 90.00 s | 查 GRID 与 bars |
| 2 | 分辨率 / 帧率 | 1080×1920 / 30fps | 报错重渲 |
| 3 | 六拍起点与小节线误差 | ≤ 1 帧（33 ms） | 改 GRID 或 bars |
| 4 | 上屏数字 = 事实表 | 100% | 打回改 facts |
| 5 | 元件越界 | 0 处（x 60–1020 / y 150–1520） | 改件参数 |
| 6 | 字幕溢出 | 0 处（≤930px） | 缩字号/折行，失败则改文案 |
| 7 | 响度 / 真峰 | −14 LUFS ±1 / ≤ −1 dBTP | 重做 loudnorm |
| 8 | 确定性 | 同帧两渲一致 | 查随机种子/跨帧状态 |

已有：1、2、8（`render.py --det` + `ffprobe`）、7（两遍 loudnorm）。

## 人（只看 3 条，2 分钟）

1. **遮住字幕看**：每拍能不能猜出在讲什么？
2. **只读字幕**：是不是一段通顺、有落点的话？
3. **手机外放**：音乐压住字幕了吗？哪一句想划走？
