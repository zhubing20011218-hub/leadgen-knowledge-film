# 06 · 合规红线（平台 + 法律）

> 引流片最容易踩的三件事：承诺收入、留联系方式、虚构案例。踩了不是"风格问题"，是限流、下架、投诉。

## 不能出现的内容

| 类别 | 不许写 | 换成 |
|---|---|---|
| 收入承诺 | "月入三万""三个月回本""稳赚不赔""包教包会" | 成本结构（进价/运费/佣金怎么算）、流程步骤、可验证的门槛 |
| 绝对化用语 | "最""第一""永久""唯一""保证" | "门槛较低""可以下班后做""少走一个坑" |
| 联系方式 | 微信、QQ、手机号、二维码、"私信发资料" | "主页合集""评论区聊" |
| 虚构案例 | 别人的店、学员收入、PS 的后台 | 自己的真实数据；没有就不讲数字 |
| 恐慌兜售 | 只讲裁员不讲出口；"再不转行就完了" | 同一句话里给出可走的下一步 |
| 医疗/金融承诺 | 疗效、收益保证、代运营包结果 | 只讲流程与规则 |

## 法律与平台层面

- **《广告法》**：绝对化用语、虚假宣传（无依据的收益承诺）属违规；
- **《人工智能生成合成内容标识办法》**（2025-09 起）：AI 生成内容要标识。做法：文件内写不可见标记 + 发布时提示用户打开平台"AI 生成"声明；画面不压水印；
- **平台导流规则**：抖音/小红书对站外导流有限制，视频里放微信号是最常见的限流原因；
- **肖像与商标**：不出现他人品牌 logo、不出现可识别的真人正脸（除非有授权）。

## 引用要给出处

规则、政策、税率这类，片上打一行小字（来源 + 年份）；查不到可靠来源的，不写。

## 每条片交付时自问

1. 这句话如果被人截图发到群里，会不会被骂"割韭菜"？
2. 片里的每个数字，我能不能当面解释清楚它是怎么算的？
3. 观众照着做，第一步能不能今天就开始？（不能 = 出口是假的）
