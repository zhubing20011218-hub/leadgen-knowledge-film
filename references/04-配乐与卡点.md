# 04 · 配乐与卡点

> 标杆样片的配乐实测 112.35 BPM，一小节 2.136 秒，**一句字幕正好一小节**——节奏感就是这么来的。
> 所以这里的规矩是反过来的：先定速度，再按"一句一小节"排字幕，画面的每一次变化都落在小节线（重拍）上。

## 默认：按片子结构自动合成（不用找音乐、没有版权问题）

`scripts/make_cues.mjs` 读 film.json，自动排出配乐（`scripts/build.sh` 会自己跑）：

| 片子里 | 配乐里 |
|---|---|
| 每一章 | 换一个和弦（Am → F → C → G 循环），pad 铺底 + 八分音符拨弦 |
| 第一章（钩子） | 只有拨弦和轻镲，留空间给第一句字幕 |
| 第二章起 | 四拍底鼓 + 二四拍拍手 + 低音拨弦进来 |
| 反转那一章（`"turn": true`，不写就是倒数第二章） | 它前一小节撤掉鼓和拨弦，只剩 pad 和一个上滑音；反转落在重拍上全编制回来 + 一记 boom |
| 每句字幕起点 | 一声很轻的 tick |
| 每章起点 | 前面一个短 whoosh，起点一声 drop |
| 片名、最后一句 | boom；最后一句再加一声 bell |

合成器是 `scripts/score.mjs`（零依赖、同样的输入永远出同样的文件，来源见 `LICENSE-THIRD-PARTY.md`）。
产物是我们自己合成的，可以随成片发布。

速度只有三档（写在 film.json 的 `bpm`）：**112（默认，和样片同速）**、128（紧张）、100（舒缓）。

## 用户自己有配乐

1. 先问清楚这首歌能不能商用（平台热门原声、来路不明的 mp3 不要用；标杆样片那首「知识大赏BGM」来源不明，**不能放进技能，也不要替用户用**）。
2. 量速度和第一拍：`ffmpeg -i 歌.mp3 -af "atrim=0:30" -f wav - | aubio tempo -i -`（没装 aubio 就请用户告诉你 BPM），第一记重拍的秒数写进 film.json 的 `phase`。
3. film.json 的 `bpm` 改成这首歌的速度；`check_film.py` 会按它重算句数。
4. 渲完画面后把歌替换掉合成配乐：
   `ffmpeg -i renders/raw.mp4 -i 歌.mp3 -af loudnorm=I=-14:TP=-1.5 -c:v copy -c:a aac -shortest -metadata comment="AIGC: 本视频由 AI 辅助生成" out.mp4`

## 混音规格

- 响度 −14 LUFS、真峰 ≤ −1 dBTP（`build.sh` 两遍 loudnorm，最后打印实测值）；
- 文件里写入不可见的 AI 生成标记（`comment` / `description` 元数据），发布时提醒用户打开平台的"AI 生成"声明；
- 没有人声。
