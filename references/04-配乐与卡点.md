# 04 · 配乐与卡点

## 三档情绪

| 档 | BPM | palette | 用在哪些角度 | cues |
|---|---|---|---|---|
| 冷峻（默认） | 120 | `poster` | A 被裁之后、B 转行盘点 | `assets/cues-120.json` |
| 紧张 | 128 | `swiss` | C 电商+AI、反转强的片 | `assets/cues-128.json` |
| 轻快 | 112 | `data` | D 我的弯路（自嘲式） | `assets/cues-112.json` |

配乐引擎：`assets/score.mjs`（MIT，来自 deepseek-opus-motion-skill，13 音色、零依赖、可循环）。
产物是我们自己的，**可以随成片发给任何人**；不要用平台热门原声、用来路不明的 mp3。

## GRID

```json
{ "bpm": 120, "t0": 0.4, "bars": [0, 3, 5, 8, 11, 13], "bar": 2.0, "beat": 0.5 }
```
- `t0` = 第一记重拍（不是 0）；
- `bars` = 六拍起点（30 秒）；60 秒 `[0,6,10,16,22,26]`；90 秒 `[0,9,15,24,33,39]`；
- 画面里所有时间 = `t0 + 拍数 × beat`，不许写死秒。

换档只改 `window.FILM_BPM`：`K = 基准小节 / 实际小节`，全片精确缩放（实测 120 BPM 30.00 s ↔ 128 BPM 28.15 s，画面代码零改动）；成片时长按 `t0 + (末拍-首拍)/K` 算。

## 段落事件（cues 写死，模型别碰）

| 小节 | 120 BPM 秒 | 事件 |
|---|---|---|
| 0 | 0.4 | pad 铺底 + 稀疏拨弦 |
| 3 | 6.4 | 加 hat + whoosh（进片名） |
| 5 | 10.4 | kick + clap + 八分拨弦 + drop（进分叉） |
| 8 | 16.4 | 保持 + knock（收窄开始） |
| 11 | 22.4 | **撤鼓**（静音坎）+ whoosh |
| 13 | 26.4 | 全编制回来 + drop（反转/出路压在重拍） |
| 14.5 | 29.4 | boom 收片 |

## 混音（机器检查）

```bash
# 1) 合成配乐（会写 ../public/score.wav，按 cues 的 bpm/时值对齐小节线）
node assets/score.mjs cues.json
# 2) 两遍 loudnorm 到 −14 LUFS / 真峰 ≤ −1 dBTP
ffmpeg -i renders/raw.mp4 -i public/score.wav -c:v copy -c:a aac -b:a 192k out.mp4
```
规格：无旁白 → 用全编制；有旁白 → 音乐 −10 dB；成片 −14 LUFS ±1、真峰 ≤ −1 dBTP、LRA ≤ 11。

## 音效（第二期）

关键动作一声，音高取曲子调性；不要每句都配。事件表用 `--events` 导出，别手写时间点。
